# A2A Deployment Guide: RecoveryIQ Agent for Prompt Opinion

This guide explains how to deploy the RecoveryIQ agent as a discoverable A2A (Agent-to-Agent) service for Prompt Opinion integration.

## Architecture

```
Prompt Opinion Platform
        ↓
(1) Discover agent via /.well-known/agent-card.json
        ↓
(2) Invoke pipeline via POST /a2a (JSON-RPC)
        ↓
RecoveryIQ Backend (FastAPI)
        ↓
Clinical LLM → Insurance RAG → Orchestrator → PromptOpinionAgent
        ↓
JSON-RPC Response (structured + plain-language markdown)
```

# Required

## API Endpoints

### 1. Agent Card Discovery

**Endpoint:** `GET /.well-known/agent-card.json`

**Purpose:** Prompt Opinion discovers the agent and its capabilities

**Response:**
```json
{
  "protocolVersion": "0.3.0",
  "name": "hackathon_recovery_intelligence_agent",
  "description": "External orchestrator agent for recovery planning...",
  "url": "https://your-domain.com/a2a",
  "preferredTransport": "JSONRPC",
  "version": "0.1.0",
  "capabilities": {
    "streaming": false,
    "pushNotifications": false,
    "stateTransitionHistory": false
  },
  "defaultInputModes": ["text/plain"],
  "defaultOutputModes": ["text/plain", "application/json"],
  "skills": [
    {
      "id": "pt_eligibility_review",
      "name": "PT Eligibility Review",
      "description": "Assess likely eligibility for additional supervised physical therapy...",
      "tags": ["clinical", "insurance", "physical-therapy", "authorization", "care-plan"],
      "inputModes": ["text/plain"],
      "outputModes": ["text/plain", "application/json"]
    }
  ]
}
```

### 2. A2A JSON-RPC Endpoint

**Endpoint:** `POST /a2a`

**Protocol:** JSON-RPC 2.0

**Request:**
```json
{
  "jsonrpc": "2.0",
  "id": "request-id",
  "method": "message/send",
  "params": {
    "message": {
      "role": "user",
      "parts": [
        {
          "kind": "text",
          "text": "Is Daniel eligible for 2x/week PT under his Kaiser plan?"
        }
      ]
    },
    "metadata": {
      "case": {
        "case_id": "CASE_003",
        "patient_summary": "30-year-old male...",
        "clinical_notes": "...",
        "pt_notes": "...",
        "imaging": "..."
      }
    }
  }
}
```

**Response:**
```json
{
  "jsonrpc": "2.0",
  "id": "request-id",
  "result": {
    "id": "task-id",
    "status": {
      "state": "completed",
      "message": {
        "role": "agent",
        "parts": [
          {
            "kind": "text",
            "text": "## Clinical Summary\n\n**Executive Summary:** Daniel is a candidate for 2x/week PT pending documentation...\n\n..."
          }
        ]
      }
    },
    "artifacts": [
      {
        "artifactId": "artifact-1",
        "name": "external_agent_response",
        "description": "Structured external-agent packet for Prompt Opinion.",
        "parts": [...]
      },
      {
        "artifactId": "artifact-2",
        "name": "plain_language_opinion",
        "description": "Plain-language clinical summary generated by PromptOpinionAgent.",
        "parts": [
          {
            "kind": "text",
            "text": "## Clinical Summary\n\n..."
          }
        ]
      }
    ],
    "metadata": {
      "case_id": "CASE_003",
      "readiness": "ready",
      "requires_human_review": false,
      "external_agent_response": {...}
    }
  }
}
```

## Pipeline Execution

When Prompt Opinion sends a message to `/a2a`, the RecoveryIQ backend:

1. **Extracts** the user question and case data from the JSON-RPC params
2. **Runs Clinical LLM** to assess clinical evidence and requirements
3. **Runs Insurance RAG** to check coverage and authorization rules
4. **Orchestrates** conflict resolution and structured decision-making
5. **Generates Opinion** via PromptOpinionAgent for plain-language markdown summary
6. **Builds Task** with both structured response and plain-language opinion
7. **Returns JSON-RPC** result with artifacts and metadata

## Supported Methods

- **`message/send`** - Send a message and run the full pipeline
- **`tasks/send`** - Alias for message/send
- **`tasks/get`** - Retrieve a previously stored task by ID
- **`agent/getAuthenticatedExtendedCard`** - Get extended agent metadata with debug endpoint

## Response Format

The A2A response includes two key artifacts:

1. **`external_agent_response`** - Structured packet with sections, confidence levels, and metadata
2. **`plain_language_opinion`** - Markdown summary from PromptOpinionAgent for human review

Both are available in the task result for Prompt Opinion to consume and present to care coordinators.

## Public Deployment

### Option 1: Cloud Deployment (AWS, GCP, Azure)

1. Deploy FastAPI app to your cloud provider
2. Configure DNS to point to your deployment
3. Ensure HTTPS is enabled
4. Prompt Opinion will discover via `.well-known/agent-card.json`

### Option 2: Reverse Proxy (e.g., nginx)

```nginx
server {
    listen 443 ssl;
    server_name recovery-iq.example.com;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Option 3: Tunneling for Testing (e.g., ngrok)

```bash
ngrok http 8000
# This gives you a public URL like https://xxxx-xx-xxx-xxx.ngrok.io
```

The base URL is automatically extracted from the incoming request, so the agent card will point to the correct public URL.

## Troubleshooting

### 503 Error from Gemini API

The Gemini API may experience temporary high demand. Wait a few minutes and retry.

### Agent Card Points to Wrong URL

The base URL is extracted from the HTTP request. Ensure:
- Reverse proxy is forwarding `Host` header correctly
- `X-Forwarded-Proto` is set to `https` if behind a proxy
- Domain is correctly configured in DNS

### Plain-Language Opinion Missing

Ensure `prompt_opinion_agent` is instantiated in `Orchestrator.from_env()`. Check logs for LLM errors.

## Architecture Notes

- **Stateless**: Each request is independent; tasks are stored in-memory
- **Synchronous**: Returns completed task immediately (not async/streaming)
- **Deterministic**: Same input produces consistent structured output (except for LLM variation)
- **Extensible**: Add new skills by updating agent card and handler logic
