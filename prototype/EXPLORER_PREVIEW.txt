KEY FEATURES:

  ✅ Agents think INDEPENDENTLY
     - Separate inputs, separate analysis, separate outputs
     - Clinical focuses on patient condition; Insurance focuses on coverage

  ✅ Evidence is TRACEABLE
     - Click any source reference (📄 clinical_notes[0]) to see the actual text
     - No hallucinations; all claims are sourced from case data

  ✅ Conflicts are DETECTED
     - Orchestrator identifies when agents disagree
     - Shows whether conflicts are BLOCKING or informational

  ✅ Resolution is STRUCTURED
     - Not guessing; rule-based resolution with clear next steps
     - Numbered workflow steps with dependencies and success criteria

  ✅ Reasoning is TRANSPARENT
     - See why each agent made its decision
     - See what documentation is missing
     - See what the next action should be

HOW TO ACCESS:

  1. Start the service:
     $ cd prototype
     $ export GEMINI_API_KEY="your-key"
     $ uvicorn src.hackathon_agent.app:app --reload

  2. Open in browser:
     http://localhost:8000/explore

  3. Click [Run Demo Case] and wait ~60 seconds for the pipeline to complete

  4. Explore the visual representation of agent reasoning and conflict resolution
